01 / Main result

A complete finite characterization.

With n storage nodes, any k nodes recover the file, and any failed node is repaired from d helpers. This note resolves the cases k = d = n − 1 for n = 6 and 7.

Theorem 1 · Information-theoretic converse and achievability
(n − 1)α ≥ Bandnr(r − 1)α + n(n − 1)β ≥ r(r + 1)B

For n ∈ {6, 7} and 1 ≤ r ≤ n − 1, these inequalities specify the closure of the achievable nonnegative region. The layered construction and space sharing achieve the full boundary.

03 / Proof structure

Condition, reduce, certify.

The induction is proved for a class of symmetric submodular systems satisfying the repair relation. This lets the smaller-node inequality apply to the contracted system, before specializing to the entropy function of a code.

  1. Start from repair

    Use outgoing rows Oi, incoming columns Ui, symmetry, and the implication h(Oi | Ui) = 0. No linear-code assumption is imposed.

  2. Contract an incoming column

    Delete node 1 and define g(X) = h(X ∪ U1) − h(U1) on surviving messages. This function again satisfies all smaller-system axioms.

  3. Match exact coefficients

    Each certificate expresses a positive multiple of the parent deficit minus a positive child deficit as a positive integer sum of conditional mutual informations.

L[pDn,r[h] − qDn−1,r[g]] = ∑t wt Ih(Xt; Yt | Rt) ≥ 0

Here Dn,r[h] = n(n − 1)h(S1→2) + nr(r − 1)h(O1) − r(r + 1)h(En). The smaller-node starting cases come from cutsets; the ten certificates supply every intervening induction step.

Symmetry and these closure equalities identify entropy coordinates. Submodularity supplies the nonnegative inequalities used in the certificate.

Finite scope. The certificates establish the complete regions through seven nodes, including the smaller cases needed by the induction. They do not establish the general-n conjecture or the (8, 7, 7) tradeoff. The note reports that attempts to extend the method further were unsuccessful.

Certificate format and search restrictions

JSON node labels are zero-based. Ordered pairs (i, j), i ≠ j, enumerate message bits lexicographically. Each term records a positive integer weight, its three sets R, X, Y, and explicit permutation witnesses for its four entropy corners.

  • After closure and removal of full rows, each conditioning set has at most n − 2 residual messages.
  • Residual edges may be disconnected or cyclic; this is an edge-count restriction, not a path-length restriction.
  • Each CMI argument is a single message or a whole outgoing row. Every retained term is tight on both adjacent complete parity layers.
  • The largest integer scale is 1282833116168492207230. Python integers retain it exactly; certificate coefficients are never rounded to floating point.

The archive reproduces exact verification and the support audit. It does not contain the large LP discovery dictionaries. The archived target uses the negative-CMI sign convention; the verifier recomputes the positive identity.
